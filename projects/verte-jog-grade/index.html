Verte jogging spot grade

For Verte

A soft morning-warmth colour grade for a Verte watch spot, designed as a custom LUT outside the editor so it could be iterated quickly.

What I built

  • 33-point .cube LUT built in Python: tone curve first, green desaturation after, warmth that fades to zero at white and in shadows
  • Skin and greens kept apart by hue, so skin never turns orange
  • The graphic end card protected by blending graded and ungraded renders frame by frame
  • Drove DaVinci Resolve's free edition through a Lua console bridge, since it has no scripting API
  • Resolve's render verified against the reference to within 2/255
