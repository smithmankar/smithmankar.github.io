Cosmic crystals and moon

For Alexandre Christie

Six crystal models and a 3D moon for the Cosmic launch, modelled in Blender and rendered live in the browser.

WHAT I BUILT
  • Per-vertex thickness baked into the crystals so light attenuates through them like real glass
  • Moon built from NASA's lunar topography, cut down from a 299 MB source to web sizes
  • GLB optimisation recipe tuned so six named crystals are never fused into one mesh
  • Rendered only while on screen, one still frame under reduced motion, and an image fallback without WebGL2
