01

The brief

I study for the IIT Madras online BS alongside a full-time job, and the study plan lived in a calendar file. I wanted a phone app that starts each block for me, records what actually happened against the plan, and plans around what is due.

It had to work on a free Apple developer account, which rules out push notifications and iCloud and makes every install expire after seven days.

02

What I built

  • Tap to start: a notification starts a block, an AlarmKit timer runs it, a Live Activity counts down on the lock screen, and the real start, pause and stop times are logged.
  • A wake-up alarm through AlarmKit, which breaks through silent mode and Focus, and a wind-down reminder.
  • Planned against actual hours per course every week, plus deadlines and a syllabus progress map.
  • Its own calendar, rewritten from the plan whenever the plan changes, and the course's live session feeds read by an iCal parser I wrote.
  • A sync server in Swift (Hummingbird and SQLite) on my home server, published through a Cloudflare Tunnel.

03

How I did it

Design first, then build28 September 2026+

Layout studies came before code. The first version was about 2,600 lines of SwiftUI and SwiftData with zero warnings, and it went onto the phone the same night.

Work within the free account+

No push and no iCloud meant offline-first from day one. Every record carries an ID, an updated time and a soft delete, so syncing could be added later without a migration. Local notifications refill a rolling window each time the app opens, because iOS caps how many can be pending.

One brain, three places12 October 2026+

The plan logic lives in a Foundation-only Swift core compiled into the app, the widget and the server, so all three compute the same plan. The server keeps SQLite inside a single actor so transactions can't interleave. It went live on 12 October, and the phone's first sync sent 85 records that matched its own data file exactly.

Safe to expose+

The server runs in Docker on my home server behind a Cloudflare Tunnel, so nothing is opened on the home network. Separate tokens cover the phone, my Mac work log and admin.

Make it feel designed12 October 2026+

When the app felt bare, two rounds of layout studies picked a new Home countdown, a full-screen focus ring and a syllabus progress map, then the screens were rebuilt to match.

04

What it changed

Study blocks start on time and the hours are real, not remembered. Each week's review reads actual numbers, and the plan adjusts to what is due next, on the phone and the server alike.
