IITM Companion

Personal project

A personal iOS app that runs my IIT Madras study plan: tap to start a block, a lock-screen countdown, and planned versus actual hours every week.

RESULTS
  • In daily use since 28 Sep 2026; the sync server has been live since 12 Oct
WHAT I BUILT
  • AlarmKit timers and Live Activities that break through silent mode and Focus
  • A gradual wake-up ramp, wake log and wind-down
  • Writes the plan to its own calendar and keeps it in sync
  • Planned versus actual hours per course, exported for a weekly review
  • Sync server in Swift that shares the app's core code, live on my home server behind a Cloudflare tunnel
