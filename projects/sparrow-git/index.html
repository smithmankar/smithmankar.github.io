Sparrow Git

For Sage Sparrows

A private VS Code extension that gives the team a visual Git workflow in the sidebar, so nobody has to fight the terminal.

What I built

  • Enforces team conventions: branch naming, commit prefixes and protected main
  • Smart Split, AI suggestions for commits, branches and PRs, and pull request review from the editor
  • Background branch health monitoring, with a lock that keeps pollers from colliding with the user's own git commands
  • Refuses commits in detached HEAD and on protected branches

export function KpiCalculator() {
  const { department } = useParams()
  const { data } = useKpiScores(department)

  return (
    <div className="grid gap-4">
      {data.metrics.map(metric => (
        <ScoreCard
          key={metric.id}
          name={metric.name}
          weight={metric.weight}
          achievement={metric.value}
        />
      ))}
      <TotalScore score={data.total} />
    </div>
  )
}
